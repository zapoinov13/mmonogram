# Архив рабочих заметок

Здесь лежат отчёты и инструкции, которые накопились в корне репозитория за время
работы над проектом: «что было сделано», «какие картинки добавить», «что
починено». Они описывают уже завершённые задачи и нужны только как справка по
истории — актуальную документацию смотрите в корне: `README.md`,
`DEPLOYMENT.md`, `QUICK_START.md`.

Файлы перенесены сюда через `git mv`, поэтому история изменений каждого из них
сохранена: `git log --follow docs/archive/<файл>.md`.
