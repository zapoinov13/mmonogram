## 📐 Адаптивные изменения:

### 1️⃣ **ИЗОБРАЖЕНИЕ**

**Мобильные (< 768px):**
```tsx
object-contain  // Машина полностью видна
```

**Планшеты (768px - 1024px):**
```tsx
object-cover  // Полное заполнение
```

**Десктоп (> 1024px):**
```tsx
object-cover  // Полное заполнение экрана
```

**Результат:**
- ✅ На мобильных машина полностью видна
- ✅ На десктопе полное заполнение экрана
- ✅ Используется вся ширина

---

### 2️⃣ **ОТСТУПЫ (PADDING)**

**Мобильные:**
```tsx
px-4 pb-6  // Компактные
```

**Планшеты:**
```tsx
px-6 pb-8  // Средние
```

**Десктоп:**
```tsx
px-8 lg:px-12 xl:px-16  // Большие
pb-12 lg:pb-16 xl:pb-20  // Большие
```

**Результат:**
- ✅ На мобильных компактно
- ✅ На десктопе просторно
- ✅ Адаптивные отступы

---

### 3️⃣ **GRADIENT OVERLAY**

**Адаптивный градиент:**
```tsx
// Мобильные: более темный (лучшая читаемость)
from-black/90 via-black/40

// Десктоп: более светлый (премиум вид)
md:from-black/80 md:via-black/20
```

**Результат:**
- ✅ Лучшая читаемость на мобильных
- ✅ Премиум вид на десктопе
