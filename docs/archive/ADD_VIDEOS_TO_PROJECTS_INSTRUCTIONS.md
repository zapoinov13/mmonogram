## 🚀 Пошаговая инструкция:

### Шаг 1: Откройте Finder
Перейдите в папку:
```
m-monogram/public/videos/
```

### Шаг 2: Перетащите видео
Перетащите ваше видео в эту папку

### Шаг 3: Переименуйте файл
1. Выделите файл
2. Нажмите `Enter` или кликните на имя
3. Переименуйте по формату: `project-[id]-video.mp4`

**Пример:**
- Если добавляете видео для проекта G900 → `g900-maybach-video.mp4`
- Если добавляете видео для проекта G63 → `g63-signature-video.mp4`

---

## ✅ Правила именования:

1. **Только маленькие буквы:** `g900-maybach-video.mp4` (не `G900-Maybach-Video.MP4`)
2. **Только `.mp4` расширение** (рекомендуется для веб)
3. **Без пробелов** - используйте дефисы `-`
4. **Формат:** `[project-id]-video.mp4`

**❌ Неправильно:**
- `G900 Video.MP4`
- `g900_maybach_video.mp4`
- `g900 video.mp4`
- `project-g900.mp4`

**✅ Правильно:**
- `g900-maybach-video.mp4`
- `g63-signature-video.mp4`
- `rr-fusion-video.mp4`

## ⚠️ Важно:

- **Формат:** MP4 (рекомендуется H.264 кодек для лучшей совместимости)
- **Размер:** Рекомендуется оптимизировать для веб (не слишком большие файлы)
- **Качество:** Высокое качество для премиального вида
- **Длительность:** Любая (рекомендуется 30 секунд - 2 минуты)
