# 🔧 Исправление названия вкладки браузера

## Проблема:
В браузере отображается "MarkVision AI - Умный маркетинг" вместо "M-Monogram"

## Причина:
Это кеш браузера. Title в `index.html` уже правильный ("M-Monogram"), но браузер показывает старое закешированное название.

---

## ✅ Решение:

### Вариант 1: Жесткая перезагрузка (Рекомендуется)

**На Mac:**
```
Cmd + Shift + R
```
или
```
Cmd + Option + R
```

**На Windows/Linux:**
```
Ctrl + Shift + R
```
или
```
Ctrl + F5
```

---

### Вариант 2: Очистить кеш браузера

**Chrome/Edge:**
1. Откройте DevTools (F12)
2. Правый клик на кнопке обновления
3. Выберите "Empty Cache and Hard Reload"

**Firefox:**
1. Откройте DevTools (F12)
2. Правый клик на кнопке обновления
3. Выберите "Очистить кеш и жестко перезагрузить"

**Safari:**
1. Cmd + Option + E (очистить кеш)
2. Cmd + R (обновить)

---

### Вариант 3: Закрыть все вкладки

1. Закройте ВСЕ вкладки с localhost:8080 и localhost:8081
2. Закройте браузер полностью
3. Откройте заново
4. Перейдите на http://localhost:8081/

---

### Вариант 4: Изменить порт

В терминале:
```bash
# Остановите текущий сервер (Ctrl+C)
# Запустите на другом порту
npm run dev -- --port 3000
```

Откройте http://localhost:3000/ - там точно будет правильное название!

---

## 🎯 Результат:

После очистки кеша вы увидите:
```
M-Monogram
```

Вместо:
```
MarkVision AI - Умный маркетинг
```

---

**Это 100% кеш браузера! Код уже исправлен! 🚀**
