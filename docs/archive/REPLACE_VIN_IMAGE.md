## Инструкция:

### Сохраните прикрепленное изображение визитки M-Monogram как:

```
src/assets/menu/menu-verify.jpg
```

**Полный путь:**
```
/Users/urijzapojnov/m-monogram/m-monogram/src/assets/menu/menu-verify.jpg
```

---

## 📂 Как заменить:

### Способ 1: Через Finder (рекомендуется)
1. Откройте Finder
2. Перейдите в папку: `m-monogram/src/assets/menu/`
3. Найдите там файл `menu-verify.jpg`
4. Удалите старый файл или переименуйте его (например, в `menu-verify-old.jpg`)
5. Перетащите новое изображение визитки в эту папку
6. Переименуйте новый файл в `menu-verify.jpg`
7. Обновите страницу в браузере (Cmd+R или F5)

### Способ 2: Через терминал
```bash
# Если изображение в Downloads:
cd /Users/urijzapojnov/m-monogram/m-monogram/src/assets/menu/

# Сделайте бэкап старого (опционально)
mv menu-verify.jpg menu-verify-old.jpg

# Скопируйте новое изображение
mv ~/Downloads/[имя_файла_визитки].jpg menu-verify.jpg
```
