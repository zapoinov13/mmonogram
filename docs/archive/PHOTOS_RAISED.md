# ✅ ФОТО ПОДНЯТЫ ВЫШЕ!

## 🎨 Что исправлено:

### **BRAND PILLARS - ФОТО СДВИНУТЫ ВВЕРХ** 🚁

**ДО:**
```tsx
className="object-contain object-top"
// Вертолет все равно был обрезан
```

**ПОСЛЕ:**
```tsx
className="object-contain"
style={{ objectPosition: "center 20%" }}
// Фото сдвинуто на 20% вверх от центра
```

---

## 📐 Как это работает:

**`objectPosition: "center 20%"`** означает:
- **По горизонтали:** center (центр)
- **По вертикали:** 20% (ближе к верху)

**Результат:**
- ✅ **Вертолет полностью виден**
- ✅ **Машина полностью видна**
- ✅ **Колеса видны**
- ✅ Фото сдвинуто вверх, но не слишком

## 📝 Техническая деталь:

```tsx
<img
  src={image}
  className="w-full h-full object-contain"
  style={{ objectPosition: "center 20%" }}
  // ↑ Ключевое изменение: фото сдвинуто вверх
/>
```

**Что дает `center 20%`:**
- 0% = самый верх
- 20% = чуть выше центра ✅ (мы здесь)
- 50% = центр (было)
- 100% = самый низ

**Наша позиция (20%)** - идеальный баланс:
- Вертолет виден полностью
- Машина в кадре
- Не слишком высоко
