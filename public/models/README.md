# Модели конфигуратора

Оцифрованные модели G63 в формате GLB со сжатием Draco. Какой файл к чему
относится, задаёт `src/components/configurator/models.ts` — этот список лишь
пересказывает его.

## Основной набор — около 10.2 МБ

Грузится всегда. Повторно оптимизированные CAD-выгрузки:

| Файл | Что внутри |
|---|---|
| `body-refined.glb` | кузов |
| `kit-refined.glb` | обвес M-Monogram и колёса |
| `interior-refined.glb` | интерьер |
| `parts/steering-wheel.glb` | руль |

Руль вынесен отдельным файлом: так можно менять качество этой заметной детали,
не переэкспортируя весь салон. В рендерере старая геометрия в зоне руля
маскируется, чтобы не было наложения двух деталей.

## Тяжёлый набор — около 66 МБ, только по `?hq=1`

Исходные плотные выгрузки. Сами не грузятся, нужны для сравнения геометрии:
`parts/stock-body.glb`, `parts/body-kit-wheels.glb`, `parts/custom-interior.glb`.

## Сравнение с CAD — только по `?cad=1`

`body-clean.glb`, `kit-grille-refined.glb`, `cad-interior-web.glb`,
`cad-steering-center.glb`, `cad-steering-controls.glb`.

Пока файлов нет, конфигуратор работает на процедурной заглушке
(`GClassModel.tsx`) — сцена не ломается.

## Как готовятся файлы

Исходные FBX конвертируются так:

```
/Applications/Blender.app/Contents/MacOS/Blender --background \
    --python scripts/fbx-to-glb.py -- <папка-с-fbx> public/models \
    --max-tris 700000 --only "body kit"
```

Тяжёлые модели гоняются по одному ключом `--only`: децимация держит всю сетку
в памяти, и на 8 ГБ система убивает процесс молча.

Прореживание идёт молча по несколько минут. Не прерывайте его и ничего не
вводите в то же окно терминала: нажатие Enter туда обрывает прогон.

Прореживать надо до сжатия, а не после: чтобы прорезать готовый GLB,
`gltf-transform` распаковывает Draco в WebAssembly, и на сотне мегабайт
сжатой геометрии этот модуль падает независимо от размера heap у Node.

Готовый GLB кладётся в `public/models` целиком: папка копируется в сборку как
есть, поэтому файл, на который никто не ссылается, всё равно уезжает на домен.
Проверить, что таких не осталось, — `npm run check:configurator`.

Структуру готового GLB — меши, полигоны, материалы, габариты — показывает
`node scripts/inspect-glb.mjs public/models/*.glb`.
